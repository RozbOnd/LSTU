\section*{Цель работы}

Освоить полный цикл разведочного анализа данных (EDA): проверку базовых предположений измерительного процесса, расчёт описательных статистик, построение и интерпретацию графиков (гистограмм, Box Plot, CDF, диаграмм рассеяния), выявление выбросов, аномалий и взаимосвязей, а также формулирование гипотез для дальнейшего моделирования.

\section*{Задачи}

\begin{enumerate}
    \item Изучить философию и цели разведочного анализа данных
\item Освоить проверку четырёх фундаментальных предположений измерительного процесса с помощью 4-Plot
\item Изучить меры центральной тенденции и меры разброса
\item Освоить построение и интерпретацию гистограмм, Box Plot, CDF и KDE
\item Изучить методы анализа взаимосвязей: диаграммы рассеяния и корреляции
\item Провести сравнительный анализ распределений по группам
\item Сформулировать гипотезы для дальнейшего моделирования 
\end{enumerate}
